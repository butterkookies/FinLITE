Proposal 2 · Stripe & Linear Calm Grid
Contextual Hover Actions & Unified Command Bar

Instead of permanent button boxes on every row, the table displays clean micro-indicators (e.g. 📎 3 receipts). When you hover over any row, a sleek action dock smoothly slides in, giving you instant access to Attach, View, or Audit.

✓ Calm Default State ✓ Quick Hover Shortcuts ✓ Zero Action Clutter ✓ Unified Single-Deck Search & Action Bar
